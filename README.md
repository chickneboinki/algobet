# LeanLab

AI-powered sports picks, live alerts, and player props.

- Run algorithms on games
- Track bets (Supabase)
- Discord bot with rich embeds + role alerts
- Auto live/final updates

## Deploy

Connected to Vercel. Set env vars:
- `OPENROUTER_API_KEY`
- `ODDS_API_KEY` (optional)
- `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`
- `DISCORD_BOT_TOKEN` / `DISCORD_GUILD_ID`

## Local

```bash
npm install
npm run dev
```
