# HelpBet

AI-powered sports algorithm platform.

- Run algorithms on games
- Track bets (Supabase)
- AI generate & learn (OpenRouter)
- Auto watcher

## Deploy

Connected to Vercel. Set env vars:
- `OPENROUTER_API_KEY`
- `ODDS_API_KEY` (optional)
- `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`

## Local

```bash
npm install
npm run dev
```
